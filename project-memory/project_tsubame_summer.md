## 1. プロジェクト概要（Sho の依頼, 2026-11-18）
- **[事実]** この冬、Sho は 燕ハイランドロッジ（妙高市、赤倉・燕温泉の近くの高所にあるホテル）を手伝う
- **[事実]** ホテル側は **夏も営業したい**。必要なのは「市場調査」と「夏の売上を実際に立てる方法」
- **[事実]** オーナーと Sho のアイデア: **毎週、知り合いのキッチンカーを呼んでイベントを開き、「行けばいつも何かやっている場所」にする**
- **[事実]** 告知のアイデア: 冬に来るインバウンド客に「夏もやっています」と伝える。**オーナーはホテルを3軒持っている**ので、どのホテルでも告知できる。近隣のホテルにも告知の協力を頼めるかもしれない
- **[事実]** Sho はプロジェクト管理を **このリポジトリ（Claude Code）** で行いたい
- **[未確認]** 現在の夏の状態（休館か、一部営業か）、客室数・料金、夏の営業期間、オーナー名と他2ホテル、予算、Sho の役割と報酬、夏の道路・アクセス、イベント・キッチンカー関連の許可、目標値

## 2. ゴール（案）— すべて [提案]。数値目標は Q3 の回答後に Fin が入れる
1. **夏季営業の可否と形を決める材料をそろえる**（市場・競合・アクセス・法令・収支の5点）— 期限案: 2027-01-31
2. **夏の売上モデルを1つに絞る**（宿泊＋週替わりイベント＋日帰り客の組み合わせ。損益分岐が見える形）— 期限案: 2027-02-28
3. **冬のシーズン中に、夏の見込み客リストを作る**（3ホテルのインバウンド客に夏の案内、関心のある人の連絡先を同意つきで集める）— 2026-12〜2027-03
4. **夏の初回イベントまでに、出店者・許可・告知・予約導線をそろえる** — 期限は夏の営業開始日（[未確認]）から逆算
5. **夏のシーズン後に振り返り、2028 年の続行可否を判断できる数字を残す**

KPI 候補 **[提案]**: 夏の客室稼働率・ADR・売上／イベント1回あたりの来場者数・キッチンカー出店数・出店者の継続率／冬の告知からの関心登録数→夏の予約転換数／近隣ホテル経由の送客数
