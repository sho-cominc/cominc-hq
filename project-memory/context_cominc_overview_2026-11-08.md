## 4. Cominca-stay. 料金（2026-11-06 時点）

1組・2名まで・素泊まり。

| 時期 | 期間 | 1週間（6〜7泊） | 1泊（2〜5泊） |
|---|---|---|---|
| 通常期 | 4月〜11月 | ¥66,000 | ¥12,000 |
| 冬の前後 | 12/1〜19、3/11〜31 | ¥71,500 | ¥13,000 |
| 冬 | 12/20〜3/10 | ¥77,000 | ¥14,000 |
| ピーク | 年末年始、2月の連休 | ¥88,000 | ¥16,000 |

- 1週間料金 = 1泊料金 × 5.5
- 清掃料 ¥4,000（1滞在につき1回）
- 3人目から 1人1泊 +¥3,000（最大6名）
- 28泊以上 25%引き
- 最低宿泊数 2泊（冬季・連休は3泊）
- 予約は **Airbnb のみ**
- **最初の3件**は Airbnb の新規割引20%が週割の代わりに適用 → 7泊は表示より ¥1,200〜1,600 高く、6泊以下は安くなる。3件たまったら `stay.ts` の `newListingOffer` を `false` にすると注記が消える
- **未確定**: 28泊以上で新規割引が月割25%の代わりになるかは不明。なる場合、ピーク期28泊で約¥22,000 高くなる

### 立地（サイト掲載OKの表現）
- ロッテアライリゾートまで**車25分**、雪道なら**約35分**。「closest major ski resort」と書く（高田の近くに金谷山の小さいゲレンデがあるため "closest" とは書かない）
- 赤倉・杉ノ原はもっと遠い。斑尾は記載しない
- 妙高高原まで約45分（※実走で確かめた時間ではない）
- **ロッテアライの名前を出すのはOK**（2026-10-29 Sho 決定）。ただし **勤務先であること・提携・社員特典があるように読める書き方はしない**
- 「日本一深いパウダー」は確かめようがないので全ページから削除済み
