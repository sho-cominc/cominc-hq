# 燕ハイランドホテル 無料送迎(駅↔ホテル) 法務チェック 2026-11-21 (Law)
前提: 一次資料(条文・通達の原文)は今回未参照。下記の通達名・条番号は記憶ベースで、原文確認までは「未確認」。確認先: 北陸信越運輸局 新潟運輸支局(上越)、新潟県警察(安全運転管理者)。
1. 道路運送法 🟢(条件つき) — 無償の送迎は、有償の運送ではないので 許可(第4条)・自家用有償運送の登録(第78条)の対象外。根拠: 道路運送法第78条、国交省通達「許可又は登録を要しない運送の態様について」(ホテル・旅館の宿泊客送迎の例。原文の文言は未確認)。
 - 🟡 宿泊料・貸切料に含まれる場合: 運送の対価を別建てで収受せず、宿泊サービスの付随であれば不要というのが通達の考え方(未確認)。「送迎料◯円」と内訳に出す・送迎だけ売る・送迎の有無で値引きする、は有償と見られるおそれ。
 - 運行主体はホテル(車両もホテル所有か、ホテルが無償で借りる)にする。ComInc.がホテルへ「送迎代」を請求する形は 🔴(ComInc.が対価を得て運ぶ形になる)。運転手への報酬は運送の対価ではないが、業務委託の形は 🟡 → 運輸支局へ事前相談(未確認)。
 - 「無料送迎」の掲載は法的には可。ただし景表法上、実際は料金に含まれるなら「無料」と書かず「宿泊料金に含まれます」と書く方が安全(有利誤認の予防)。
2. 非宿泊者 🟡 — 無償なら許可不要の原則は同じだが、不特定多数(登山客等)の定期運行は「宿泊サービスの付随」でなくなり、疑義が出る。レストランのみの客は「予約した飲食客」に限り、運賃・寄付・最低注文額での実質対価は不可。登山客への開放は 🔴寄り(行わない/相談後)。
3. 車両 🟡 — 乗車定員11人以上(例 14人乗りハイエース): 運転に中型免許(2017/3以降の普通免許は不可。Sho/Yukariの免許種別は未確認)。10人以下でも車両総重量3.5t以上は準中型。30人以上は大型。
 - 定員11人以上の白ナンバー: 安全運転管理者の選任・届出(道路交通法第74条の3、施行規則第9条の8)、アルコール検知器による確認(2023/12〜)。
 - 保険: 自賠責+任意保険(対人対物無制限、搭乗者傷害/人身傷害、使用目的「業務」、運転者の年齢・範囲にヘルパーを含める)。契約者は運行主体のホテルに。保険内容は代理店に確認(未確認)。
 - 32人は1台で運べない。複数回運行か2台。大型バスの借上げは貸切バス事業者に委託(第4条許可の事業者のみ)。
4. 旅行業法 🟡 — ホテルが自社の宿泊・自社車両の送迎・自社(テナント含む)の食事だけを自分の名前で売る場合は、第三者サービスの「手配」ではないため旅行業登録は不要の見込み(第2条。未確認)。
 - 登録が要り得る(🔴): 他社のサービス(新幹線切符、外部ガイドのアクティビティ、貸切バス、他施設の宿泊)を組み込んで売る / ComInc.が報酬を得てホテルの部屋と体験を組み合わせて売る / 海外の旅行会社向けの受け地手配(旅行サービス手配業の登録、第23条の2以降、未確認)。
 - 直接契約はホテル↔チーム。ComInc.は紹介料・手数料を取らない形か、取るなら要相談。
5. 🔴 一覧: (a)ComInc.が送迎代を請求/対価を得て運ぶ形 (b)送迎料の別建て表示 (c)登山客など一般公開 (d)外部サービス入りパッケージの販売 (e)免許不適合での11人以上運転。
