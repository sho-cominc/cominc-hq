## 2. 11-23 レビューの評価
- 妥当・大きさも適切: 消費税（影響最大）、カード手数料、社保。ただし次の補足が必要
  - 消費税は保守的すぎる面あり。課税事業者なら仕入税額控除（リネン・OTA手数料・光熱費など）で数十万円戻る。簡易課税などの選択も含め、課税事業者か・誰の事業か は未確認（Law／税理士）
  - OTA手数料は税込の宿泊料にかかり、手数料自体にも消費税が含まれる。本表は控除なしで保守的に処理
  - 社保 約15%（健保・厚年・拠出金・雇用・労災の概算。料率は年度で変わる、未確認）。加入要件と、ゆかりさんの雇用主（誰か）も未確認。有給付与（6か月超）の費用も未計上
- 抜けていたもの（影響順）
  1. OTA比率: 半分・12%は仮定。全員OTAなら25%で約86万円減（カード分を相殺後）。比率と料率は未確認
  2. 固定費60万円の中身: 保険・固定資産税・修繕・消耗品・通信を含むか、営業しない月の費用は別か、開業前費用（備品・許可・仕入れ・宣伝）は未確認。減価償却は改修をオーナーが支払い済みのため本表には不要
  3. 入湯税（燕温泉。額・特別徴収は妙高市の定めで未確認）: 預かり金で原則売上外。料金に含めて吸収する場合は例として2名×150円×488泊＝約15万円（25%時）
  4. 宿泊税: 有無は未確認
  5. 資金繰り: OTAの入金は後払い（時期は各社で未確認）。4月開業前に運転資金が先行する
  6. Sho の税: 個人事業主として所得税・住民税・事業税・国保がかかる。事業税の区分は未確認、手取りは別計算（本表は税引前）
  7. レストラン: 25%が税込・税抜どちらの売上にかかるか未確認（差は約13万円）。軽減税率（持ち帰り8%）の扱い、宿泊客の客数が含まれるか、パート費、かき氷機リースも未確認
  8. NP の定義、清算頻度、書面契約は未確認（§1-2 のとおり）。レストランが NP の内か外かで Sho と John の取り分が変わる
- 見方: 25%時、Sho の客室取り分（約155万）はレストランの手残り（税込前提で約207万、人件費前）より小さい。Sho 側の収入はレストランの比重が大きい
