## 2. 進め方（ステップ）

1. **冬（12〜3月）: 見込み客を集める**
   - QR カードを3ホテルに置く。受付で一言添える
   - アンケートの回答を月1回集計（何に関心があるか、どこの国の人か、何人登録したか）
2. **1月: 夏の形を決める**
   - 料金（39,000円／人数別）、貸切プラン、送迎、レストランのメニューと営業時間
   - アンケートの途中結果で「冷泉」「サウナ」「音楽イベント」などへの関心を見る（冷泉は希望があれば7月までに工事）
3. **2月: 売る場所を整える**
   - 予約サイトに4〜11月のプランを公開（冷泉は「7月から」と明記）
   - 公式サイトに夏の情報を追加、または新しく作る（§3 の John の回答次第）
4. **3月: 登録者に案内を送る**
   - 「料金と予約開始のお知らせ」＋特典（直接予約10%オフ、宿泊者に1杯）
5. **4〜11月: 営業しながら集客**
   - 登山口・温泉目当ての立ち寄り客をレストランへ。飲んだら泊まれる（1人5,000円、空室時のみ。店内でだけ案内）
   - 集客できる人を呼べたときに音楽イベント
   - 平日は海外チームの貸切を狙う

## 4. ホームページに足すとよいもの（提案）

- **トップ**: 「4〜11月も営業」の一文と、夏の写真1枚
- **夏の過ごし方**: 妙高山登山口、燕温泉の外湯（黄金の湯・河原の湯）、滝、星空、ホタル、紅葉
- **レストラン**: 朝カフェ・ランチ・夜バー（0時まで）、ペレット窯ピザとビール、かき氷とコーヒー
- **泊まり方**: 1室39,000円（4名まで、布団）。4名なら1人1万円以下
- **貸切・リモートワーク**: 1棟8室・最大32名、平日向け、Wi-Fi と作業スペース（要確認）、駅送迎は宿泊料金に含む
- **アクセス**: 上越妙高駅・関山駅から、車で約20分（幹線道路・高速から）
- **英語ページ**: 海外チームと冬の客向け
- **直接予約フォーム**: 10%オフ特典の受け皿
- 注意: 「冷泉」は工事が終わるまで「7月から」と書く。送迎は「無料」ではなく「宿泊料金に含まれます」と書く（法務メモ参照）

### 日帰り客（地元の人・登山客）の呼び方（2026-11-23 追加）
宿泊なしで「一度行ってみよう」と来る人向け。目的はイベント、ピザ、かき氷、温泉、登山。
- 見つけてもらう: Googleマップ／道の駅・観光案内所・関山駅にチラシ（置けるか要確認）／地域のウェブニュースやラジオにお知らせ（無料）／出店者（ブラックパフェなど）のSNS
- 来る理由: 4月に「地元デー」（オープン記念）／季節の一品（新緑・ホタル・紅葉）／登山のあとにピザとビール／イベントの日はキッチンカー
- また来てもらう: LINE公式アカウント（無料）／スタンプカード（例: 5回でかき氷1杯）／帰りに次のイベント案内
- 追加費用: 約5万円（印刷とスタンプ特典）
- 注意: 日帰り入浴を売るなら公衆浴場の許可が別に必要（今の許可は未確認）
