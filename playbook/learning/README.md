# 学習ノート — エージェントがレベルアップする仕組み

エージェントは**会話をまたいで記憶を持たない**。毎回、定義・プレイブック・このフォルダを読んでから仕事を始めるだけ。
だから「成長」とは、**次の自分が読むファイルに、学んだことを書き残すこと**。このフォルダがその場所。

## 全体の流れ
```
Sho が素材を置く（inbox.md / チャットにスクショ）
   ↓
① 学ぶ   担当エージェントが素材を見て「何が・なぜ効いているか」を書き出す
   ↓
② 書く   learning/<name>.md に「仮説」として追記（出典・日付つき）
   ↓
③ 使う   次の仕事で、その仮説を実際に提案に入れる（「学習ノート #n を適用」と明記）
   ↓
④ 判定   Sho の反応・数字（保存数・予約・CTR など）で 仮説 → 定着 / 却下
   ↓
⑤ 昇格   定着したものだけ、Hana の振り返りで playbook/<role>.md のルールに移す
```

## 全員のルール
1. **仕事の最初に** `playbook/learning/<自分の名前>.md` を読む（ファイルがなければ作らなくてよい。学ぶときに作る）
2. **素材から学ぶときは、真似ではなく原理を抜き出す**。他人のデザイン・コピー・写真をそのまま流用しない（著作権・ブランドの両面）
3. 1件の書き方（下のテンプレ）を守る。**見たこと（事実）と、そこからの解釈（仮説）を分ける**
4. **ComInc. のブランドと方針に照らしてから書く**。合わない学びは「ComInc. には合わない理由」を書いて却下にする。それも立派な学習
5. 市場・トレンドの情報は**日付と出典が必須**。前年比はコロナ禍の底を基準にしない（会社の方針）
6. **Sho のフィードバックが一番強い教材**。「これいい」「これは違う」と言われたら、理由ごと記録する
7. 1ファイル 150 行まで。超えたら Hana の振り返りで整理（定着は playbook へ、却下・古いものは末尾の「アーカイブ」へ）

## 1件のテンプレ
```markdown
### #<連番> <一言タイトル> — <YYYY-MM-DD>
- 出典: <URL / スクショ / Sho の発言 / 自分の過去作>
- 見たこと: <観察できる事実だけ。色・余白・構図・言い回し・数字>
- なぜ効いている（仮説）: <原理>
- ComInc. での使い方: <どの成果物で、どう使うか。ブランドとの相性>
- 状態: 仮説 / 試行中（<どこで使ったか>）/ 定着（<根拠>）/ 却下（<理由>）
```

## 素材の渡し方（Sho 向け）
- **Instagram・X・Pinterest などはログインが必要で、エージェントは中を見られないことが多い**（クラウド環境では instagram.com 自体に接続できない）。
  → **スクリーンショットをチャットに貼る**のが一番確実。画像ならデザインも文字も読める
- 一言でいいので「どこに惹かれたか」を添える（例:「余白の取り方」「最初の1行で止まった」）。その一言が学習の質を大きく上げる
- すぐ学ばせない素材は `inbox.md` に貼っておく。「@clare inbox を学習して」でまとめて処理できる
