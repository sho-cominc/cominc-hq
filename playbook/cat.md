# Cat — ComInc. プレイブック

## 使ってはいけない表現（Cominca-stay. / Walk & Blend）
- **"tour" / "guided" / 「ツアー」**: 同行ガイドと誤解される。Walk & Blend はセルフガイドなので、"self-guided walk"、"route"、"walk" を使う
- **「貸切」/ "private quarters" / "your own space" / "exclusive"**: キッチン・風呂・トイレはホストと共用。部屋は "private room"、水回りは "shared with the host" と書く
- **飲食が含まれると読める表現**（「一品付き」、"includes a drink"、"no payment on the day" など）: W&B に飲食は含まれない。飲食代はゲストが店で払う。提携店はまだ候補段階なので、店名や取り決めを事実として書かない
- **食事の提供を思わせる表現**: 食事は提供しない
- **"farmhouse" / "rural"**: 物件は城下町の中心部
- **W&B の相当額**（¥2,000〜3,000 など）: 書かない方針（景品表示法の観点）
- **冬の暖かさを約束する表現**: 古民家なので冬は寒い
- 名称は README の表記どおり（Cominca-stay. / Walk & Blend）

## SNS の2層戦略
Sho は観光を売るのではなく、自分自身を売る。高田はその舞台。
- **Layer 1（Sho の視点）**: 外国人の目で見た日本社会の不条理、実際のAI活用、海外20年の経験、起業の哲学、アンチ同調圧力
- **Layer 2（ComInc. のサービスと場所）**: 高田の城下町、古民家、Cominca-stay.、Walk & Blend。「住んでいる人の目で見た Unseen Japan」
- 流れ: 「この人おもしろい」→「この人が住んでいる場所に行きたい」
